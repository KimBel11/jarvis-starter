# The Jarvis Mac app (optional)

Jarvis already works in your browser at http://localhost:4777. The Mac app wraps it in its own window with a menu-bar orb, Cmd+J to talk, and microphone and file support. **No Apple account needed.**

1. Install **Xcode** (free, Mac App Store) and open it once.
2. In the `mac-app` folder, right-click **`install-mac-app.command` → Open**.
3. After a few minutes **Jarvis** is in your Applications folder and opens. Make sure Jarvis is running (`start.command`, or it starts at login if you said yes during setup).
If macOS says the app cannot be opened: System Settings → Privacy & Security → "Open Anyway".
