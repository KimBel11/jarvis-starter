# Make Jarvis yours

- **Your assistant**: name and personality: Agent team → your assistant → Edit & access.
- **Agents**: Agent team → ＋ New agent. Pick a name, role, which AI (Claude, Codex, Gemini or an API model), tools (read-only or edit), the project it belongs to, and whether it must show a plan and wait for your approval (recommended for anything that changes files or spends money). Starter agents: Researcher, Developer, Writer, Video Producer, Video Intel, 3D Artist.
- **Who leads**: the Claude / Codex switch on Home. *Always both* = both answer and one reviews the other.
- **Skills**: Plugins & skills. Install ready-made skills or write your own: a folder with a `SKILL.md` file describing when and how to use it.
- **Council**: ask a hard question; several AIs answer separately, then judge each other.
- **Projects**: Projects → ＋ New project, or drop a folder named "<Name> Project" into your Jarvis Workspace.
- **Obsidian**: Tools & integrations → Obsidian → Build the Jarvis Hub. You get a notes vault with one note per project and a graph view.
- **VS Code**: Tools & integrations → VS Code → open a project's folder in one click.
- **iMessage**: Tools & integrations → iMessage: text your assistant from your iPhone (follow the steps on that page; it needs macOS permissions).
- **Voice**: Vault & keys → add an ElevenLabs key for natural voices; pick the voices on the Settings page.
- **Look**: Settings → Appearance (colors, orb, background).
- **Notifications**: only approvals, failures and your daily summary notify you. Everything else stays quiet.
- **Profile picture for Jarvis in iMessage**: Jarvis has a ready picture for every orb style and colour (50 in total, in `public/avatars`). Each time you change the orb or the colour in Settings → Appearance, Jarvis texts you the matching picture with a link and the steps to save it and set it as the *Jarvis* contact photo. (Needs iMessage control turned on under Tools & integrations. Apple does not let any app change a profile photo by itself, so you tap to set it once per change.)
